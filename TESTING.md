# Проверка обновления 1.5.0

Дата: 23 сентября 2026.

Пройдены **36 автоматических проверок**: 7 проверок фонового кода в Node VM и 29 браузерных сценариев. Использованы Node.js 24.19.0 и Chromium Headless Shell 151.0.7922.34. Синтаксис всех JavaScript-файлов и тестов проверен отдельно; версии манифеста, handshake и протокол компонентов согласованы.

Проверены:

- Смена ID, замена DOM и перезагрузка страницы с сохранённым профилем.
- Привязка к двум соседям, к одному соседу и к соседям внешнего контейнера; устойчивые семантические атрибуты.
- Вставка блока перед ориентирами, исчезновение цели, изменение структуры, дублирование и исчезновение ориентиров; приоритет точного селектора и проверка позиционных селекторов.
- Независимость keep/hide, прежние профили, нормализация дополнительных полей, повторный запуск фонового кода и параллельное сохранение из двух вкладок.
- Запасной поиск ячейки (3, 4) в CSS Grid после смены идентификаторов всех ячеек; контейнер `body`, выбранные потомки ячеек и несколько одновременно скрытых блоков.
- Отказ сетки при изменении размерности, числа ячеек, структуры содержимого, объединённых ячейках и противоречащих распознанных соседях.
- Реальное применение CSS из `content.js`, восстановление выбранного DOM в редакторе без ложного признака несохранённых изменений, сохранение из предпросмотра и повторное применение скрытия без потери привязки к схлопнувшейся сетке.

Необработанных ошибок JavaScript в браузерных сценариях не обнаружено. Команда запуска (требуются современный Node.js, Playwright и установленный Chromium):

```powershell
node --test tests/background.test.cjs tests/hide-relative.test.cjs
```

Пути к тестовым runtime можно настроить по `tests/README.md`. Тесты используют локальные синтетические страницы и имитацию Chrome Extension API; установленное расширение в пользовательском Chrome не проверялось. Исторические проверки версий 1.4.x ниже полностью не повторялись.

Для ручной проверки перезагрузите расширение и вкладку сайта, откройте **Убрать → Изменить выбор → Сохранить**. Новые привязки появятся у найденных блоков; блоки, которые уже не находятся по старым правилам, нужно выбрать заново.

# Проверка ViewBlock 1.4.0

Дата: 18 сентября 2026.

## Результаты

Пройдена 81 группа проверок:

- 20 — фоновый код: протокол, проверка отправителей и popup, регистрация сайта, keep/hide, сохранение и сброс, пустые hide-профили, миграция ручных правил, передача команды видимости, независимые наборы, очередь параллельных записей, применение уже активного режима и сброс до первого сохранения.
- 8 — нормализация: режимы, старые профили, пустое скрытие, отклонение неверных данных и сохранение только допустимых полей, миграция в два набора и независимое сохранение/переключение.
- 12 — обычный режим оставления: выбор, размер, сохранение, работа кнопок, динамическая страница, исчезновение и возвращение блоков, перезагрузка, отмена и сброс.
- 8 — помощник: верхний слой, перемещение, перекрытые элементы, сохранение, смешанные версии, выбранные блоки, полная страница, модальные окна и небольшая видимая область.
- 10 — оба универсальных режима на очищенной структуре почтового интерфейса: ручное скрытие выбранных областей, сохранность остальных элементов, CSS-селекторы, кнопки строк после замены DOM и позднее содержимое. Новые невыбранные объявления остаются видимыми, как требует универсальный режим.
- 7 — полное скрытие помощника: работа фильтра и кнопок сайта, скрытая перезагрузка, приостановка черновика/клавиш/маски, повторное открытие, переключение режимов и применение сохранённого профиля при скрытом черновике.
- 7 — меню расширения: карточки обоих режимов со счётчиками, применение сохранённого результата, продолжение черновика, отдельное редактирование, помощник, пауза, подтверждение сброса, отказ в разрешении и несовместимый процесс. Быстрые действия доступны без прокрутки при высоте 600 px.
- 9 — память режимов: сохранённые наборы и несохранённые черновики keep/hide, перезагрузка, отмена только текущего черновика, скрытие помощника, замена DOM, пустое скрытие, повторное применение активного режима и сброс черновиков без записи в storage. Модель хранилища не генерирует события при записи того же значения или удалении отсутствующего ключа.

Использован Chromium Headless Shell 151.0.7922.34. Проверялись настоящий код, DOM, CSS, отрисовка и ввод. Фоновый код проверялся в Node VM. Chrome Extension API заменены тестовыми реализациями; сохранение между загрузками моделировалось локальным тестовым хранилищем.

Просмотрены снимки меню обоих режимов и помощника. Ошибок JavaScript и внешних запросов в проверенных браузерных сценариях не обнаружено. Синтаксис JavaScript, версия манифеста и содержимое ZIP проверены отдельно.

## Границы проверки

Полный интеграционный запуск установленного расширения не выполнен: доступный Chrome for Testing ранее завершился до запуска с Windows SideBySide error. Headless Shell не предоставляет среду расширений. Реальный диалог разрешений, жизненный цикл service worker, автоматическая инъекция и перезапуск Chrome требуют проверки установленного экземпляра.

Chrome пользователя и авторизованная Почта не использовались. Тестовая почтовая страница содержит только очищенную структуру HTML, локальные стили и вымышленные письма; исходные скрипты и данные аккаунта не выполнялись. Исходное вложение, тесты и копии страницы в ZIP не включены.

После обновления перезагрузите расширение и вкладку сайта. Сохраните разные блоки в обоих режимах, переключитесь «Оставить → Убрать → Оставить», затем обновите страницу. Проверьте продолжение черновика и быстрые действия помощника. Несохранённые черновики остаются только в памяти текущей вкладки.
