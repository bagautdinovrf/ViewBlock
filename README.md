# ViewBlock 1.5.0

Расширение Chrome для настройки видимых областей страницы. Два универсальных режима работают на обычных HTTP/HTTPS-сайтах:

- **Оставить блоки** — показывать только выбранные области и их содержимое.
- **Убрать блоки** — скрывать выбранные области, сохраняя остальную страницу.

Требуется Chrome 114 или новее. Сборка и сервер не нужны: расширение использует JavaScript, HTML, CSS и Manifest V3.

## Установка и обновление

1. Поместите папку `ViewBlock` с файлами расширения в постоянное место.
2. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
3. Выберите папку `ViewBlock`, содержащую `manifest.json`.
4. Закрепите значок ViewBlock через меню расширений Chrome.

Для обновления замените файлы в прежней установленной папке. Нажмите круглую стрелку на карточке ViewBlock в `chrome://extensions`, проверьте версию **1.5.0**, затем обновите вкладку сайта. Нужны обе перезагрузки: расширения и страницы.

Работающие компоненты проверяют совместимость версий. Если появилась инструкция перезагрузки или прежняя ошибка «Недопустимый интерфейс», выполните шаги обновления выше. Удалять расширение не требуется.

## Быстро скрыть помощник

Нажмите **Скрыть** в заголовке помощника или на его свёрнутой плашке. Та же команда доступна через значок ViewBlock в панели Chrome → **Скрыть помощник**. Исчезнут окно, маленькая плашка, подсветка и область перехвата нажатий. Сохранённая фильтрация продолжит работать.

Чтобы вернуть окно, нажмите значок ViewBlock в панели Chrome → **Показать помощник**. Видимость запоминается отдельно для сайта и сохраняется после обновления страницы. Вкладки одного origin получают настройку вместе.

Если скрыть помощник во время выбора, редактирование приостанавливается, а страница возвращается к сохранённым правилам. Несохранённый выбор остаётся в памяти текущей вкладки до её обновления. **Показать помощник** позволяет продолжить выбор. Клавиши выбора не перехватываются, пока помощник скрыт.

**Свернуть** в заголовке помощника оставляет небольшую перемещаемую плашку. **Скрыть** убирает помощник полностью.

## Выбор областей

1. В меню ViewBlock выберите карточку **Оставить** или **Убрать**. Для нового режима откроется выбор блоков. Если режим уже настроен, карточка сразу применяет сохранённый результат; для редактирования нажмите **Изменить выбор**. При первом использовании разрешите доступ к текущему сайту.
2. Нажимайте на нужные области страницы. Выбранные блоки появятся списком в помощнике.
3. Кнопка **+** рядом с выбранным блоком расширяет его до родительского контейнера; **−** возвращает к предыдущему размеру; **×** удаляет блок из выбора.
4. Нажмите **Предпросмотр**, затем **Сохранить**. `Enter` также сохраняет выбор. **Отменить изменения** / `Esc` отменяет изменения текущего режима и возвращает сохранённый вид страницы; черновик другого режима остаётся доступным.

У каждого режима независимый набор блоков. Переключение **Оставить → Убрать → Оставить** восстанавливает соответствующий выбор; сохранение одного режима не изменяет другой. Сохранённые наборы переживают перезагрузку страницы и Chrome. Одновременно применяется один режим.

Во время редактирования помощник также запоминает отдельные черновики обоих режимов. На карточке видно количество блоков и состояние **сохранено** / **не сохранено**. Черновики существуют в текущей вкладке до её обновления: для постоянного хранения нажмите **Сохранить** в каждом изменённом режиме. Переключение в сохранённый режим из редактора показывает предпросмотр, который можно применить кнопкой **Сохранить**. Кнопка **Изменить выбор** открывает полную страницу для редактирования — это не сбрасывает сохранённый результат.

Старые настройки автоматически переносятся в соответствующий режим. Если другой набор был перезаписан ещё в версии 1.3.0, восстановить его задним числом невозможно.

**Удалить все настройки сайта** открывает подтверждение. После подтверждения удаляются оба сохранённых набора и черновики текущей вкладки.

Окно помощника перетаскивается за заголовок, располагается в верхнем слое браузера и удерживается внутри видимой области. После сохранения остаётся список блоков и кнопка **Изменить выбор**. Открытие выбора из меню показывает помощник, даже если он был скрыт.

Выбранные элементы остаются на своих местах, со своими обработчиками и состоянием. Расширение не копирует и не переносит их.

## Скрытие блоков с меняющимися идентификаторами

Режим **Убрать блоки** сохраняет дополнительные привязки при выборе и сохранении блока:

- Положение относительно ближайших соседей с уникальными устойчивыми признаками: ID, семантическими атрибутами или классами. Если такие соседи есть только у внешнего контейнера, сохраняется также путь от контейнера к выбранному блоку.
- Строку и столбец в CSS-сетке с постоянным контейнером, если раскладку можно однозначно определить. Этот запасной способ учитывает размерность сетки, число ячеек и структуру блока.

Если идентификатор блока изменился или сайт заменил его новым элементом, расширение сначала использует обычный селектор, затем соседние привязки и, наконец, ячейку сетки. Для позиционных селекторов сохранённые привязки проверяются в первую очередь: вставка другого блока выше не должна сдвигать скрытие.

Два соседних ориентира должны указывать на один блок. При одном ориентире проверяется также расстояние до противоположного края контейнера. Если хотя бы один ориентир распознаётся, но соседняя привязка больше не совпадает, сетка не может переопределить этот результат. Изменение числа элементов на пути, исчезновение блока, неоднозначные соседи или перестроение сетки могут остановить запасной поиск; остальные выбранные блоки продолжат скрываться. Сетка поддерживается для обычных CSS Grid с отдельными, неперекрывающимися ячейками; сложные объединённые ячейки не используются как запасная привязка.

**Для правил, сохранённых до 1.5.0, один раз откройте «Изменить выбор» и нажмите «Сохранить», пока блоки присутствуют на странице.** Так появятся новые привязки. Если старый селектор уже не находит блок, выберите его заново. Режим **Оставить блоки** сохраняет прежний способ поиска.

## Перекрывающиеся блоки

Наведите курсор на нужный участок страницы, нажмите **Все слои**, выберите элемент в списке **Блоки под курсором** и нажмите **Добавить блок**. Так можно выбрать перекрытый DOM-элемент, включая элементы, пропускающие нажатия.

`[` / `]` или `Alt` + колесо мыши перебирают слои. `+` / `−` меняют размер рамки под курсором. `Пробел` добавляет подсвеченный блок.

В дополнительных настройках можно ввести CSS-селектор. Он должен находить ровно один элемент. Можно сохранить до 32 отдельных блоков. «Все слои» выполняет ограниченный поиск; если достигнут предел, уточните участок или используйте селектор.

## Полная страница

**Показать полную страницу** в меню расширения или после сохранения в помощнике приостанавливает фильтрацию. Профиль остаётся сохранённым и может быть включён снова.

Во время выбора эта кнопка возвращает полную страницу для дальнейшего редактирования, сохраняя черновик. Кнопка **Предпросмотр** снова показывает результат.

В режиме **Оставить блоки** исчезновение одного из обязательных блоков возвращает полную страницу, чтобы пользователь не оказался в неполном интерфейсе. В режиме **Убрать блоки** исчезновение одного блока не мешает скрывать остальные выбранные области.

Пустой список в режиме **Убрать блоки** означает, что ничего не скрывается. Режим **Оставить блоки** требует хотя бы одну область.

## Обновление прежнего режима Почты

Отдельная кнопка «Только почта» и автоматическое распознавание рекламы удалены. Теперь на Яндекс Почте, как на любом другом сайте, выберите **Убрать блоки**, отметьте рекламные области и сохраните результат.

Старые профили «Только почта» открываются как **Убрать блоки**. Ранее добавленные вручную селекторы сохраняются. Автоматически распознававшиеся объявления нужно выбрать вручную: специальных скрытых правил для Яндекса больше нет.

## Данные и разрешения

Профили и видимость помощника хранятся в `chrome.storage.local`, отдельно по origin (протокол, домен, порт). Пути URL, параметры запроса и фрагменты страницы не сохраняются. Правила содержат CSS-селекторы, теги, режим и переключатель включения; селектор может включать `aria-label`. Для скрытия дополнительно сохраняются селекторы соседей и контейнера, относительные позиции, путь по элементам DOM и сведения о сетке и структуре блока. Текстовое содержимое блоков для этих привязок не сохраняется. Несохранённый выбор существует только в памяти вкладки.

- `activeTab` — доступ к активной странице после нажатия значка.
- `scripting` — запуск локальных файлов расширения на выбранном сайте.
- `storage` — локальные настройки.
- Необязательные разрешения HTTP/HTTPS запрашиваются для текущего хоста.

Расширение не отправляет данные по сети, не использует аналитику, внешние библиотеки или удалённый код. Тексты писем, значения полей, cookies и пароли не сохраняются.

## Ограничения и проверка

Это визуальная фильтрация: сетевые запросы, скрипты, видео и звук не блокируются. Пустые колонки и отступы могут сохраняться, если они заданы самим сайтом.

Внутренности iframe, canvas и Shadow DOM отдельно не выбираются; можно выбрать компонент или контейнер целиком. `chrome://`, Chrome Web Store и некоторые служебные страницы не поддерживаются.

В режиме **Оставить блоки** меню и диалоги вне выбранных областей тоже могут скрываться. Верните полную страницу и уточните выбор, если нужен такой элемент. На сайтах с нестабильной разметкой селекторы иногда нужно выбрать заново.

Работа проверена на локальных тестовых страницах с настоящим DOM и имитацией Chrome Extension API. Полный установленный экземпляр в Chrome пользователя не проверялся. Подробности — в `TESTING.md`.
