# 1.5.0

- «Убрать блоки» сохраняет положение относительно соседних блоков со стабильными признаками, в том числе через внешний контейнер. Смена ID и замена элемента больше не требуют повторного выбора при сохранении этих привязок.
- Добавлен запасной поиск по строке и столбцу CSS-сетки внутри постоянного контейнера, с проверкой раскладки и структуры блока.
- Неоднозначные совпадения и изменившаяся структура не используются для запасного скрытия. Новые привязки сохраняются отдельно в наборе режима; «Оставить блоки» работает по прежним правилам.
- Старые правила поддерживаются. Чтобы добавить привязки, нужно один раз повторно сохранить выбор, пока блоки находятся на странице.
- Протокол обновлён до 4, чтобы старый фоновый процесс не терял новые поля правил. После обновления перезагрузите расширение и вкладку сайта.

# 1.4.0

- Исправлена потеря выбора при переключении «Оставить» и «Убрать». У каждого режима свой сохранённый набор и черновик в текущей вкладке.
- Сохранение одного режима не перезаписывает другой. Настройки прежних версий автоматически переносятся; записи из разных вкладок выполняются последовательно.
- Карточка настроенного режима сразу применяет его результат. Отдельная кнопка «Изменить выбор» открывает редактор; несохранённый черновик можно продолжить.
- Меню и помощник показывают количество блоков и состояние сохранения. Добавлены понятные названия областей, объяснения предпросмотра и отмены, подтверждение удаления обоих наборов.
- Переключение уже активного сохранённого режима корректно завершает редактирование. Сброс работает даже до первого сохранения.
- Протокол обновлён до 3. После обновления требуется перезагрузить расширение и вкладку сайта.

# 1.2.0

- Помощник и подсветка вынесены в верхний слой браузера через Popover API, чтобы обычные слои страницы их не перекрывали. Минимальная версия Chrome — 114.
- Помощник можно перетаскивать за заголовок. В нём видны выбранные блоки и доступны «Сохранить», «Показать полную страницу» и редактирование выбора. После сохранения окно остаётся доступным.
- Добавлен выбор перекрывающихся DOM-блоков: «Все слои», список «Блоки под курсором» и «Добавить блок». Для уточнения границ используются кнопки + / −.
- «Только почта» заменяет прежний пресет «Только письма · Яндекс»: сохраняет весь интерфейс Почты и скрывает распознанные рекламные контейнеры и подтверждённые карточки рекламы. Правые виджеты, папки, поиск, письмо и навигация не исключаются целиком.
- В режиме «Только почта» можно дополнительно выбрать скрываемые блоки вручную. Режим можно сохранить и без ручных правил.
- Окно расширения показывает новый режим и доступное количество скрытых рекламных областей. Старые профили выбранных блоков поддерживаются.
- Распознавание зависит от структуры сайта и не гарантирует скрытие будущих форматов рекламы. Проверки выполняются на локальных страницах с синтетическими данными; пользовательская авторизованная Почта не проверена.
